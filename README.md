# RetailPulse — Retail Data Engineering Pipeline

## Project Overview

RetailPulse is an end-to-end Data Engineering portfolio project that processes retail orders, customer information, and product data.

The objective is to build a reliable data pipeline that ingests raw data, validates it, transforms it, and makes it available for business analysis.

## Technology Stack

- Python
- Pandas
- PySpark
- SQL
- Git and GitHub
- AWS S3
- AWS Glue
- Amazon Athena
- Amazon CloudWatch
